# Milestone 0 — terrain spike

The 25 km pointy-top odd-r grid is 134 × 134 (17,956 cells), fitted to the 2021 cartographic extent plus 200 km. `world.json` is 792,767 bytes and `sources.json` 5,783 bytes. All 13 P/T have owned land. Keep 25 km: no measured reason to increase it.

The GIS preprocessing is a separate, repeatable step, not a pipeline dependency: `uv run --with rasterio --with shapely --with pyproj --with fiona python scripts/preprocess_world.py`, then `uv run --with fiona --with pyproj --with shapely python scripts/add_rivers.py`. `pipeline build` runs these when the interim is absent. The MRDEM elevation overview is a nearest-neighbour 16× extract (approximately 480 m); the land-cover overview remains a 64× extract (approximately 1.92 km). A 6 km lattice within each hex samples the products. Refresh the elevation extract with `uv run --with rasterio python scripts/extract_rasters.py nrcan_mrdem`. Only samples inside the owning P/T count. Seven points on a 2 km rasterized boundary determine ownership; centre breaks ties. Interior cartographic rings and NRCan Atlas waterbodies are treated as lakes; Natural Earth 1:50m lake polygons supplement water classification on foreign land only; ocean cells near land or with ETOPO depth less than 200 m are coast. Narrow features can disappear at this scale. The lower 60% valley-floor rule and SPEC relief thresholds are applied. Elevation remains null if unavailable. Foreign elevation is not sampled. Census divisions are deferred beyond this terrain spike.

NALCMS codes: 1,2 → evergreen; 5 → deciduous; 6 → mixed; 8,11 → shrub; 10,12 → grass; 13,16 → barren; 14 → wetland; 15 → crop; 17 → urban; 19 → ice. Water/nodata are excluded; urban takes precedence at 30%. The underlying 2020 product has reported overall accuracy of about 86.9%; the coarse extraction and lattice add sampling uncertainty.

## Fidelity and relief follow-up

The map now fills the canvas with deep ocean and fades classified water and foreign terrain at the grid edge. Original procedural tree, crop, tundra, ice, mountain and elevation-shading marks add relief; foreign land remains muted. The large title overlay has been removed in favour of a compact header, and a clickable, draggable and keyboard-operated minimap was added. The US-side Great Lakes are present in the NRCan Atlas data; Natural Earth supplements other foreign lakes. The overview and coastline remain schematic at this grid size.

The former 64× elevation overview smoothed variation. In an audit of two mountainous hexes, 47 paired points per hex, without ownership filtering, had standard deviations of 228 and 275 m at 64× versus 280 and 334 m at native 30 m; the 16× values were 284 and 334 m. Point RMSE against native values fell from 152 to 60 m and 171 to 73 m respectively. This is a small diagnostic sample, not a national accuracy estimate. The SPEC thresholds and low valley-floor rule are unchanged. Among the 5,764 Canadian land hexes, relief counts flat/hills/mountains/peaks changed from 4,087/1,166/510/1 to 4,010/1,103/650/1; high-mean (at least 1,500 m) hexes with flat or hills relief fell from 50 to 27. Peak class requires a mean of at least 2,700 m, not a maximum. The coarser lattice and overview remain approximations; no elevations were invented.

In headless Chromium in this environment, the map's loading indicator disappeared after 159 ms at 1440×900 and 136 ms at 390×844; a 12-step drag and wheel gesture, including a 100 ms wait, took 767 ms. These are automated local measurements, not mid-range laptop or phone hardware benchmarks or isolated first-paint timings. English and French loading copy, French and camera hash restoration, drag, wheel, minimap pointer/keyboard navigation, help attribution and mobile control visibility were exercised. The six screenshots are in `/workspace/canada-civ-runs/screens/`.

Residual gaps versus usaciv: procedural marks and relief are simpler and more repetitive; coastlines, lakes and borders remain coarse hex approximations; the data-extent fade is visible over foreign land. Performance has not been measured on the specified physical mid-range laptop and phone. No city banners, yields, lenses or advisors were added. No usaciv source was copied.

Commands run: `uv run python -m pipeline build`, `uv run python -m pipeline check`, `uv run python -m unittest discover -s tests`, `uv run python -m pipeline serve`, JavaScript syntax checks and a headless Chromium/Playwright verification and screenshot script.
